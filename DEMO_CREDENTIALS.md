## How to Test the System

### As a Patient (Booking Appointment):
1. Go to the home page
2. Find Dr. Farhana Rahman in the doctor list
3. Click on her profile
4. Click "Book Appointment"
5. Fill in patient details:
   - Name
   - Email
   - Phone
   - Date of Birth
   - Appointment Date & Time
   - Any symptoms/notes
6. Submit the appointment

### As a Doctor (Managing Appointments):
1. Go to Doctor Login page
2. Login with Dr. Farhana Rahman's credentials above
3. View all appointments in the dashboard
4. Confirm, cancel, or complete appointments
5. Manage availability schedule

### As an Admin:
1. Go to Admin Login page
2. Login with admin credentials above
3. View dashboard with 4 cards showing:
   - Pending registration requests
   - Verified doctors count
   - Total doctors
   - Total appointments
4. Switch between 3 tabs:
   - **Registration Requests**: Review and approve/reject new doctor registrations
   - **All Doctors**: View all doctors and manage their verification status
   - **Appointments**: View all appointments across all doctors with patient details
